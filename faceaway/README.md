# FaceAway (built by Bbokari)

Bbokari builds and runs this for you: 🛡️ FaceAway → 🔨 Set up / Update FaceAway.
It compiles `FaceAway.swift` + `GlanceFace.swift` into `~/FaceAway/faceaway` and copies the ArcFace model next to it.

Face recognition is adapted from Glance (https://github.com/jonnyoo/glance), MIT License © 2026 Jonathan Zhou
(see LICENSE-glance.txt). The ArcFace model comes from InsightFace (w600k_mbf), which is for personal,
non-commercial use only.
